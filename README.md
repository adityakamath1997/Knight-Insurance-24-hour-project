# Knight Insurance - Submission Review

## Known limitations and assumptions

- Packet shape: each submission packet is assumed to contain one broker email (pasted text, or one `.txt`/`.eml` upload; pasted text wins if both are given), one application PDF, one vehicle schedule CSV, and zero or one loss runs PDF. The supplied materials do not specify file counts; extra files of the same type are not handled specially (only the first CSV is counted).
